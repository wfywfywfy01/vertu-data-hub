# ADR 0001：PDCA 与经销商知识库采用 API 边界

## 状态

已接受，2026-08-19。

## 背景

PDCA 已有用户、角色、销售归属和工作流。资料底座需要独立处理对象存储、ETL、向量检索和多媒体任务。两个系统共享数据库表会放大发布耦合和越权风险。

## 决策

- `PDCA-agent` 拥有页面、登录、角色、组织关系和业务工作流。
- `dealer-knowledge-hub` 拥有经销商知识主表、资产、版本、处理、检索、引用和导出审计。
- 浏览器只访问 PDCA；PDCA 后端用短期签名服务令牌调用知识库私有 API。
- 知识库再次校验调用者角色和经销商范围，不能只信任页面参数。
- 两个服务可使用同一 RDS 实例，但使用独立数据库和独立最小权限账号。
- 禁止跨仓库代码导入和跨数据库直接读表。

## 后果

两个仓库可独立部署和回滚；接口需要版本管理和契约测试。旧 `vertu-store-agent` 的可用解析能力迁入后冻结，不再作为运行时依赖。
