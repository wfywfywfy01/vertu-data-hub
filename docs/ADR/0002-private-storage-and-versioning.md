# ADR 0002：私有对象存储与不可变版本

## 状态

已接受，2026-08-19。

## 背景

经销商资料包含合同、联系人、图片和视频。文件较大、来源混乱，并可能出现重名、重复和修订版本。

## 决策

- 使用一个私有 OSS bucket，并按环境和经销商分区：
  - `<env>/dealers/<dealer_id>/original/`
  - `<env>/dealers/<dealer_id>/derived/`
  - `<env>/quarantine/`
  - `<env>/exports/`
- 原文件只追加，不覆盖；数据库保存对象键、哈希、大小、媒体类型和版本关系。
- 内容哈希用于完全重复检测；同一逻辑资料的新内容形成新版本。
- 派生物记录处理流水线版本，可删除后重建。
- 所有读取使用短期签名 URL；bucket 不公开。
- 启用 OSS 版本控制，删除默认采用软删除。

## 后果

存储成本略增，但可追溯、可重放和可恢复。对象移动由受控任务执行，不能靠人工改目录表示业务状态。
